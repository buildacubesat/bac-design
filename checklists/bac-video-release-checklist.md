# BAC Video Release Checklist

The steps for releasing a YouTube devlog episode. Git is this checklist's history.

Pre Release

Verify

- Watch the entire video in 1x speed with headphones  
- Pay attention to spelling, links that should be included in readme and YT cards that should be added  
- Take notes

Drive

- Upload video file to video folder  
- Perhaps delete preview file  
- Make thumbnail (perhaps A/B variants)  
- Upload outputs and materials to video folder (png, jpg, webp)

Sheets

- Update Content Plan entry: Status, video link, title, slug, hero, tags, release date, length, sponsoring notes and payment status

Repo

- Write description lead, add time stamps, don't forget sponsor mention/URL, external links and bottom video id  
- Make txt file with bac-markdown-to-youtube  
- Update upcoming content with bac-update-content-plan  
- Push all in one with "Release ..." message

YouTube

- Upload video, add URL to Content Plan  
- Paste URL and length to Content Plan  
- Upload thumbnail (up to three for A/B testing)  
- Paste title (up to three for A/B testing)  
- Paste description  
- Check that @ mentions work  
- Verify: Brand partnership or collaboration  
- Paste in tags  
- Import end cards from other video  
- Add cards if needed (refer to script or watch-through)

Ko-Fi

- Paste YT URL  
- Paste title  
- Paste lead  
- Add tag  
- Schedule 5 mins after YT release

Patreon

- Paste YT URL  
- Paste title  
- Paste lead  
- Add tag  
- Schedule 5 mins after YT release

LinkedIn

- Upload video (max 15 min), perhaps make separate version for linkedin.  
- Upload thumbnail  
- Use Claude to generate post form YT lead in and video script  
- Use hashtags and mentions

Sponsor Comms

- Send URL with release time in their time zone via email or discord  
- Thank them, say looking fwd to next collaboration  
- If applicable: Confirm you added them as brand partner or collaborator on YT

After release:

Discord

- Post in \#announcements with personalized message (not YT lead)  
- If applicable, mention related CTA or other news

YouTube

- If applicable, make pinned post for sponsor  
- If applicable, share link in Post or Short a few days later
